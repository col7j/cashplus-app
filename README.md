# كاش بلس (Cash Plus) 💸
> **"فلوسك تستاهل أكثر"** — تطبيق مالي تقدمي (PWA) متكامل لإدارة المصاريف والميزانيات والثروة الشخصية باللغة العربية مع المزامنة السحابية.

---

## 🌟 المميزات الرئيسية

- **نظام حسابات متعدد**: الحسابات الجارية، بطاقات مدى وفيزا، المحافظ الرقمية، والنقد.
- **تتبع التدفق المالي بدقة**: من لحظة الاكتساب، إلى التوزيع في المحافظ، وحتى الصرف الدقيق.
- **تحليل رسائل البنوك الذكي (SMS Parser)**: استخراج بيانات العمليات تلقائياً من رسائل البنوك السعودية ونقاط البيع و Apple Pay.
- **ميزانيات ذكية وأسقف إنفاق**: متابعة دورية ومؤشرات بصرية لتجاوز الحدود.
- **إدارة الديون والالتزامات**: تتبع المستحقات لك وعليك مع التذكيرات.
- **صناديق الادخار والأهداف**: تخصيص مبالغ للطوارئ والأهداف المستقبلية.
- **محفظة الاستثمارات**: متابعة العوائد وقيمة الأصول والمحافظ دورياً.
- **مزامنة سحابية عبر Firebase**: تسجيل دخول آمن بـ Google ومزامنة فورية عبر Firestore بين كافة أجهزتك.
- **دعم كامل للعمل بدون إنترنت (PWA & Offline-First)** مع خط ثمانية سانز (Thmanyah Sans) والتصميم الداكن والفاتح.

---

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية**: Vanilla JavaScript (ES Modules) + HTML5 + CSS3 Variables.
- **الخطوط**: خط ثمانية سانز العربي (Thmanyah Sans).
- **السحابة وقواعد البيانات**: Google Firebase (Authentication + Cloud Firestore).
- **التخزين المحلي**: LocalStorage / IndexedDB Fallback.
- **المعايير**: Progressive Web App (PWA) قابلة للتثبيت على كافة الأجهزة (iOS, Android, macOS, Windows).

---

## 🚀 التشغيل المحلي

1. استنسخ المستودع:
```bash
git clone https://github.com/col7j/cashplus-app.git
cd cashplus-app
```

2. شغّل خادم محلي:
```bash
# باستخدام Python:
python3 -m http.server 8080

# أو باستخدام Ruby:
ruby -run -ehttpd . -p8080
```

3. افتح المتصفح على: `http://localhost:8080`
